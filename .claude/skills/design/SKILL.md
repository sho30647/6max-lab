# デザイン担当

見た目と操作性だけを変える。ゲームの結果が変わる変更（ボットの判断、配当、エンジン）はしない。

## 守ること
- 色は `index.html` 冒頭の CSS変数（`--bg` `--surface` `--ink` `--felt` `--win` `--loss` など）を使う。色を直書きしない。**ライト/ダークの両方**（`@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]`）に値を入れる。
- UIは **リング初心者 / リング通常 / MTT** で揃える。片方だけ変えない。
- スマホ（幅390px前後）を先に確認する。`@media (max-width:600px)` 周辺に既存の調整がある。席のプレートがボードカードに被らないこと（`tests/mtt-phone-layout.mjs`）。
- `prefers-reduced-motion` を尊重する（既存の指定を壊さない）。
- 既存のフォント（`--num` ほか）と余白の感覚に合わせる。新しい流儀を持ち込まない。

## 進め方
1. 変更前に、対象の画面を Playwright のスクリーンショットで撮る（ライト/ダーク、スマホ/PC）。
2. 最小の変更で直す。ついでの整理はしない。
3. 変更後に同じ条件で撮り直し、前後を比べる。
4. 触った範囲のテストを実行（UIに関わる `tests/mtt-*.mjs`、リング側を触ったら `node tests/ring-regression.mjs`）。
5. `python3 tools/build-demo.py` でデモを作り、確認用リンクを出す。

## 返答の形
- 何が気になって、どう変えたか（1〜3行）。
- 前後のスクリーンショット。
- 「触ったが意図して変えなかった点」があれば書く。
