# デザインノート

デザイン担当（`.claude/agents/design.md`）が毎回読む、このアプリの見た目の約束事と判断の記録。色を決めたり変えたりしたら、ここを更新する。

## アクションの色（ライト / ダーク）

レンジ表・席の文字・吹き出しで、同じアクションは同じ色にする。

| アクション | 変数 | ライト | ダーク | 備考 |
|---|---|---|---|---|
| レイズ/ベット | `--rz` | `#D2601C` | `#E8793A` | 吹き出しは `#D2601C` |
| コール | `--sd` | `#3A6FB0` | `#6B9BDB` | 吹き出しは `#2F6FB3` |
| オールイン | `--jam` | `#9B1FE8` | `#A93DF5` | 吹き出し・席の文字も同色 |
| フォールド | （直書き） | `#7C8790` | 同左 | 吹き出しは `#8C8C8C`、席の文字は `--muted` |
| チェック | （直書き） | 吹き出し `#E6F0FA` | 同左 | |

## 意味が決まっている色

- `--win`（緑）/ `--loss`（赤）: 収支・正解/不正解。**アクションには使わない**。
- `--turn`（青）: 手番の枠。
- `--brass`: ヒーローの枠・強調。

## 乖離表示（レンジ比較）

アクション色と混同しないよう、別の色相にしている。

| 意味 | 色 |
|---|---|
| 広すぎ（ルース） | `rgb(214,51,108)` ピンク赤 |
| 狭すぎ（タイト） | `rgb(30,122,69)` 緑 |
| 種類違い | `rgb(107,68,35)` 茶 |

## 色を決めるときのやり方

- 通常の見え方に加えて、色覚シミュレーション（赤緑・青黄）でも、アクション同士の色差（CIE Lab）が十分あること。
- 白い文字を載せる色は、暗めにする（吹き出し・マスの文字）。
- 色だけに頼らず、凡例とラベルの文字でも区別できるようにする。
- `tests/range-raise-color.mjs` が、レンジ凡例・吹き出し・席の文字の色差を見ている。
