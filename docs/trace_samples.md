# 新ボットの判断トレースの説明文（サンプル）

指示書12章の形式で、ノード種別ごとに1例ずつ載せています。生成方法は `node tests/spec-samples.mjs` です。全席を新ボットにして、固定の乱数で 200 配牌を打ち、各種別の最初の例を取りました。ベットする局面では、ベットした例を優先しています。

カードは ♠♥♦♣ で表します。金額の bb はビッグブラインドの枚数、パーセントは特に断りがなければポットに対する割合です。説明文はすべて、判断のときに記録した数値だけからテンプレートで作っています。

## CB・バレル（cbet）

```text
【フロップ：UTGのボット、Q♠A♠ / ボード 9♣K♦Q♦】
結論：ポットの25%をベット（1.1bb）

① 状況
  事実：シングルレイズポット（SRP）。ボットはUTG（IP：後に行動する側）。自分がアグレッサー（前のストリートで最後に打った側）。SPR（有効スタック÷ポット）は約21.8。
  判断：CB・バレル（アグレッサーが続けて打つ）を打つかどうかの局面。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。
② これまでの行動とレンジ
  事実：BBのOOP側のチェック（アグレッサーではない側。ドンクをほぼ打たないので絞らない）で、レンジの各バケットに倍率（1／1／1／1／1）を掛けた。BBの今のレンジ：ナッツ級5%・バリュー15%・マージナル28%・ドロー3%・エア50%。
  判断：相手のレンジの構成は大きくは変わっていない。以降の勝率は、この絞り込んだレンジに対して計算する。
③ ボード
  事実：K・Qハイ、連結が強い（高連結）、同じスートが2枚（ツートーン）、ペアなし。次のカードでボットのレンジの平均勝率が5pt以上動くのは、全体の6%のカード。
  判断：次のカードで形勢がほとんど変わらない「静的」なボード。
④ 有利不利
  事実：ボットのレンジのBBのレンジに対する平均勝率は60%（レンジ優位 +10.2pt）。相手に80%以上勝てる手の割合は、ボット13%、BB5%（ナッツ優位 +8pt）。ボットの最強クラスの手の中心はKQo・JTs・99。BBの今のレンジには、KQoは38%、JTsは65%、99は50%が残っている（同じクラスの全コンボを100%としたとき）。
  判断：レンジ全体でこちらが有利。高い頻度で打てる。最強クラスの手をこちらが多く持つ。大きく打てる。
⑤ 打ち方の方針
  事実：レンジ優位とナッツ優位から補間した目標ベット頻度は75%（補正後）、サイズはポットの29%。候補サイズは25%。補正：静的なボードなのでサイズを一段小さくした。
  判断：小さいサイズで、レンジの広い範囲を打つのが基本方針。
⑥ このハンドの強さ
  事実：BBの今のレンジに対する勝率69%。次のカードで勝率が80%以上に上がる確率9%、50%未満に下がる確率0%。ボットのレンジの中では上から43%の位置。ボットの2枚は、相手のコールする手の11%、降りる手の8%を消している（ブロッカー）。
  判断：相手のレンジの多くに勝っている「バリュー」帯。この先強くなる見込みは小さい。逆転される心配は小さい。
⑦ アクションの比較
  事実：ポットの25%ベットでは、BBのレンジの26%が降り、7%がレイズし、コールしてくる手に対する勝率は66%。期待値はチェック3.11bb、25%ベット3.304bb。レンジ全体のベット頻度を目標（75%）に近づけるため、ベットの期待値に一律でポットの11%を足して比べた（調整後の頻度72%）。調整後の1番目と2番目の差はポットの約16%。
  判断：コールしてくる手にも勝っている（ベットがバリューになる）。迷う余地がないので毎回この行動。
⑧ レイズされた場合
  事実：BBのレイズレンジ（6.2bbへのレイズを想定）に対する勝率8%、コールに必要な勝率30%。
  判断：レイズされたら降りる（bet/fold）。
```

## ドンク（donk）

```text
【フロップ：BBのボット、J♠Q♣ / ボード 9♣K♦Q♦】
結論：チェック

① 状況
  事実：シングルレイズポット（SRP）。ボットはBB（OOP：先に行動する側）。相手がアグレッサーで、ボットが先に行動する。SPR（有効スタック÷ポット）は約21.8。
  判断：ドンク（アグレッサーより先に打つベット）の局面。原則はチェック。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。
② これまでの行動とレンジ
  事実：前の判断のあと、相手のレンジを絞る行動はなかった。UTGの今のレンジ：ナッツ級13%・バリュー42%・マージナル28%・ドロー0%・エア17%。
  判断：相手のレンジの構成は大きくは変わっていない。以降の勝率は、この絞り込んだレンジに対して計算する。
③ ボード
  事実：K・Qハイ、連結が強い（高連結）、同じスートが2枚（ツートーン）、ペアなし。次のカードでボットのレンジの平均勝率が5pt以上動くのは、全体の6%のカード。
  判断：次のカードで形勢がほとんど変わらない「静的」なボード。
④ 有利不利
  事実：ボットのレンジのUTGのレンジに対する平均勝率は41%（レンジ優位 −9.5pt）。OOPなのでエクイティを実現しにくい分3ptを引き、実効のレンジ優位は−12.5pt。相手に80%以上勝てる手の割合は、ボット5%、UTG13%（ナッツ優位 −8pt）。ボットの最強クラスの手の中心はJTo・99・JTs。UTGの今のレンジには、JToは0%、99は50%、JTsは100%が残っている（同じクラスの全コンボを100%としたとき）。
  判断：レンジ全体で相手が有利。打つ頻度を下げる。最強クラスの手は相手のほうが多い。大きく打つと危険。
⑤ 打ち方の方針
  事実：レンジ優位とナッツ優位から補間した目標ベット頻度は0%（補正後）、サイズはポットの63%。候補サイズは50%と33%。補正：OOPなので頻度を一段下げた。静的なボードなのでサイズを一段小さくした。ドンクの局面で、有利なカードが落ちていないので打たない。OOPなので、ナッツ級の手の20%はチェックに残す。
  判断：この局面では打たない（全体でチェック）。
⑥ このハンドの強さ
  事実：UTGの今のレンジに対する勝率59%。次のカードで勝率が80%以上に上がる確率4%、50%未満に下がる確率11%。ボットのレンジの中では上から22%の位置。ボットの2枚は、相手のコールする手の13%、降りる手の0%を消している（ブロッカー）。
  判断：勝ち負けがほぼ半々「マージナル」帯。この先強くなる見込みは小さい。逆転される心配は小さい。
⑦ アクションの比較
  事実：ポットの50%ベットでは、UTGのレンジの1%が降り、10%がレイズし、コールしてくる手に対する勝率は62%。ポットの33%ベットでは、UTGのレンジの1%が降り、10%がレイズし、コールしてくる手に対する勝率は62%。期待値はチェック2.253bb、50%ベット2.068bb、33%ベット2.102bb。
  判断：どのサイズでも、ベットする理由（バリュー・エクイティ否定・セミブラフ・ブラフ）が成り立たないのでチェック。迷う余地がないので毎回この行動。
⑧ レイズされた場合
  事実：チェックしたので、レイズされる場面はない。
  判断：相手がベットしてきたら、そのとき⑦の手順（コールに必要な勝率との比較）で決める。
```

## プローブ（probe）

```text

  判断：プローブ（相手のチェックでレンジの上限が抑えられた前提で打つベット）の局面。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。3人以上なのでマルチウェイの簡易ルール（ブラフを減らし、バリューの基準を上げる）を使う。
```

```text
【ターン：SBのボット、7♥7♠ / ボード 3♥A♥A♠6♦】
```
