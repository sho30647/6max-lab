# 新ボットの判断トレースの説明文（サンプル）

指示書12章の形式で、ノード種別ごとに1例ずつ載せています。生成方法は `node tests/spec-samples.mjs` です。全席を新ボットにして、固定の乱数で 200 配牌を打ち、各種別の最初の例を取りました。ベットする局面では、ベットした例を優先しています。

カードは ♠♥♦♣ で表します。金額の bb はビッグブラインドの枚数、パーセントは特に断りがなければポットに対する割合です。説明文はすべて、判断のときに記録した数値だけからテンプレートで作っています。

## CB・バレル（cbet）

```text
【フロップ：UTGのボット、Q♠A♠ / ボード 9♣K♦Q♦】
結論：ポットの50%をベット（2.3bb）

① 状況
  事実：シングルレイズポット（SRP）。ボットはUTG（IP：後に行動する側）。自分がアグレッサー（前のストリートで最後に打った側）。SPR（有効スタック÷ポット）は約21.8。
  判断：CB・バレル（アグレッサーが続けて打つ）を打つかどうかの局面。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。
② これまでの行動とレンジ
  事実：BBのOOP側のチェック（アグレッサーではない側。ドンクをほぼ打たないので絞らない）で、レンジの各バケットに倍率（1／1／1／1／1）を掛けた。BBの今のレンジ：ナッツ級5%・バリュー15%・マージナル26%・ドロー8%・エア47%。
  判断：相手のレンジの構成は大きくは変わっていない。以降の勝率は、この絞り込んだレンジに対して計算する。
③ ボード
  事実：K・Qハイ、連結が強い（高連結）、同じスートが2枚（ツートーン）、ペアなし。ボットのレンジで今いちばん強い20%の手のうち、次のカードの後にその20%から落ちる手は、カードの平均で35%。
  判断：次のカードで形勢がある程度変わりうる「中間」なボード。
④ 有利不利
  事実：ボットのレンジのBBのレンジに対する平均勝率は60%（レンジ優位 +10.2pt）。相手に80%以上勝てる手の割合は、ボット13%、BB5%（ナッツ優位 +8pt）。ボットの最強クラスの手の中心はKQo・JTs・99。BBの今のレンジには、KQoは38%、JTsは65%、99は50%が残っている（同じクラスの全コンボを100%としたとき）。
  判断：レンジ全体でこちらが有利。高い頻度で打てる。最強クラスの手をこちらが多く持つ。大きく打てる。
⑤ 打ち方の方針
  事実：レンジ優位とナッツ優位から補間した目標ベット頻度は75%（補正後）、サイズはポットの62%。候補サイズは50%と75%。
  判断：高い頻度で、中くらいのサイズで打つのが基本方針。
⑥ このハンドの強さ
  事実：BBの今のレンジに対する勝率69%。次のカードで勝率が80%以上に上がる確率9%、50%未満に下がる確率0%。ボットのレンジの中では上から43%の位置。ボットの2枚は、相手のコールする手の13%、降りる手の7%を消している（ブロッカー）。
  判断：相手のレンジの多くに勝っている「バリュー」帯。この先強くなる見込みは小さい。逆転される心配は小さい。
⑦ アクションの比較
  事実：ポットの50%ベットでは、BBのレンジの42%が降り、6%がレイズし、コールしてくる手に対する勝率は57%。ポットの75%ベットでは、BBのレンジの56%が降り、5%がレイズし、コールしてくる手に対する勝率は49%。期待値はチェック3.11bb、50%ベット3.285bb、75%ベット3.2bb。1番目と2番目の差はポットの約2%。
  判断：コールしてくる手にも勝っている（ベットがバリューになる）。ほぼ互角なので確率で混ぜる（チェック0%・ベット100%）。乱数0.627でベットを選んだ。
⑧ レイズされた場合
  事実：BBのレイズレンジ（9bbへのレイズを想定）に対する勝率5%、コールに必要な勝率30%。
  判断：レイズされたら降りる（bet/fold）。
```

## ドンク（donk）

```text
【フロップ：BBのボット、J♠Q♣ / ボード 9♣K♦Q♦】
結論：チェック

① 状況
  事実：シングルレイズポット（SRP）。ボットはBB（OOP：先に行動する側）。相手がアグレッサーで、ボットが先に行動する。SPR（有効スタック÷ポット）は約21.8。
  判断：ドンク（アグレッサーより先に打つベット）の局面。原則はチェック。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。
② これまでの行動とレンジ
  事実：前の判断のあと、相手のレンジを絞る行動はなかった。UTGの今のレンジ：ナッツ級13%・バリュー42%・マージナル24%・ドロー5%・エア17%。
  判断：相手のレンジの構成は大きくは変わっていない。以降の勝率は、この絞り込んだレンジに対して計算する。
③ ボード
  事実：K・Qハイ、連結が強い（高連結）、同じスートが2枚（ツートーン）、ペアなし。ボットのレンジで今いちばん強い20%の手のうち、次のカードの後にその20%から落ちる手は、カードの平均で36%。
  判断：次のカードで形勢が大きく変わりうる「動的」なボード。
④ 有利不利
  事実：ボットのレンジのUTGのレンジに対する平均勝率は41%（レンジ優位 −9.5pt）。OOPなのでエクイティを実現しにくい分3ptを引き、実効のレンジ優位は−12.5pt。相手に80%以上勝てる手の割合は、ボット5%、UTG13%（ナッツ優位 −8pt）。ボットの最強クラスの手の中心はJTo・99・JTs。UTGの今のレンジには、JToは0%、99は50%、JTsは100%が残っている（同じクラスの全コンボを100%としたとき）。
  判断：レンジ全体で相手が有利。打つ頻度を下げる。最強クラスの手は相手のほうが多い。大きく打つと危険。
⑤ 打ち方の方針
  事実：レンジ優位とナッツ優位から補間した目標ベット頻度は0%（補正後）、サイズはポットの63%。候補サイズは100%と75%。補正：OOPなので頻度を一段下げた。動的なボードなのでサイズを一段大きく、頻度を一段下げた。ドンクの局面で、有利なカードが落ちていないので打たない。OOPなので、ナッツ級の手の20%はチェックに残す。
  判断：この局面では打たない（全体でチェック）。
⑥ このハンドの強さ
  事実：UTGの今のレンジに対する勝率59%。次のカードで勝率が80%以上に上がる確率4%、50%未満に下がる確率11%。ボットのレンジの中では上から22%の位置。ボットの2枚は、相手のコールする手の15%、降りる手の0%を消している（ブロッカー）。
  判断：勝ち負けがほぼ半々「マージナル」帯。この先強くなる見込みは小さい。逆転される心配は小さい。
⑦ アクションの比較
  事実：ポットの100%ベットでは、UTGのレンジの16%が降り、9%がレイズし、コールしてくる手に対する勝率は56%。ポットの75%ベットでは、UTGのレンジの12%が降り、9%がレイズし、コールしてくる手に対する勝率は57%。期待値はチェック2.253bb、100%ベット1.729bb、75%ベット1.917bb。
  判断：どのサイズでも、ベットする理由（バリュー・エクイティ否定・セミブラフ・ブラフ）が成り立たないのでチェック。迷う余地がないので毎回この行動。
⑧ レイズされた場合
  事実：チェックしたので、レイズされる場面はない。
  判断：相手がベットしてきたら、そのとき⑦の手順（コールに必要な勝率との比較）で決める。
```

## プローブ（probe）

```text

結論：ポットの100%をベット（6bb）

  判断：プローブ（相手のチェックでレンジの上限が抑えられた前提で打つベット）の局面。スタックが深く（SPR 6超）、このハンドで全額を入れる展開ではない。
② これまでの行動とレンジ
  事実：BBのIPのチェックバックで、レンジの各バケットに倍率（0.3／0.6／1／0.6／0.7）を掛けた。BBの今のレンジ：ナッツ級18%・バリュー7%・マージナル17%・ドロー13%・エア45%。
  判断：相手のレンジは弱い手に寄った（ナッツ級＋バリューが22%→16%）。以降の勝率は、この絞り込んだレンジに対して計算する。
③ ボード
  事実：Aハイ、やや連結（半連結）、同じスートが2枚（ツートーン）、ペアボード。新しいカードはそれまでの最高位より上のカード（オーバーカード）。ボットのレンジで今いちばん強い20%の手のうち、次のカードの後にその20%から落ちる手は、カードの平均で32%。
  判断：次のカードで形勢がある程度変わりうる「中間」なボード。
④ 有利不利
  事実：ボットのレンジのBBのレンジに対する平均勝率は56%（レンジ優位 +5.7pt）。OOPなのでエクイティを実現しにくい分3ptを引き、実効のレンジ優位は+2.7pt。相手に80%以上勝てる手の割合は、ボット30%、BB18%（ナッツ優位 +12.4pt）。ボットの最強クラスの手の中心はA8o・A7o・A5o。BBの今のレンジには、A8oは75%、A7oは68%、A5oは75%が残っている（同じクラスの全コンボを100%としたとき）。
  判断：レンジ全体ではほぼ互角。最強クラスの手をこちらが多く持つ。大きく打てる。
⑤ 打ち方の方針
  事実：レンジ優位とナッツ優位から補間した目標ベット頻度は39%（補正後）、サイズはポットの77%。候補サイズは100%と125%。補正：OOPなので頻度を一段下げた。ターンなのでサイズを一段大きくした。OOPなので、ナッツ級の手の20%はチェックに残す。
  判断：強い手とブラフに絞り、大きいサイズで打つのが基本方針。
⑥ このハンドの強さ
  事実：BBの今のレンジに対する勝率38%。次のカードで勝率が80%以上に上がる確率0%、50%未満に下がる確率83%。ボットのレンジの中では上から73%の位置。ボットの2枚は、相手のコールする手の4%、降りる手の11%を消している（ブロッカー）。

⑦ アクションの比較
  事実：ポットの100%ベットでは、BBのレンジの75%が降り、2%がレイズし、コールしてくる手に対する勝率は0%。ポットの125%ベットでは、BBのレンジの75%が降り、2%がレイズし、コールしてくる手に対する勝率は0%。期待値はチェック1.926bb、100%ベット2.979bb、125%ベット2.63bb。レンジ全体のベット頻度を目標（39%）に近づけるため、ベットの期待値に一律でポットの-15%を足して比べた（調整後の頻度53%）。調整後の1番目と2番目の差はポットの約3%。
  判断：降りてもらう分と、コールされても勝つ分（ガットショットやバックドアの見込みを含む）を合わせると、チェックより得なので、ブラフとして打てる。コールしてくる手には負けている（打つと強い手にだけコールされる）。迷う余地がないので毎回この行動。

  判断：レイズされたら降りる（bet/fold）。
```
